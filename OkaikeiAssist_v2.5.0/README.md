# お会計アシスト v2.5.0

## ファイル構成
- `index.html`：画面
- `style.css`：デザイン
- `app.js`：計算・履歴・設定などの処理
- `manifest.json`：PWA設定
- `service-worker.js`：オフラインキャッシュ
- `icons/`：ホーム画面用アイコン

## GitHub Pagesでの公開
1. GitHubで新しいPublicリポジトリを作成します（例：`okaikei-assist`）。
2. このフォルダーの中身を、リポジトリの最上位（root）にアップロードします。外側のフォルダーごと入れ子にしないでください。
3. `Settings` → `Pages` → `Build and deployment` を開きます。
4. `Deploy from a branch`、Branch=`main`、Folder=`/(root)` を選び、Saveします。
5. 数分後、`https://ユーザー名.github.io/リポジトリ名/` で公開されます。

## スマートフォンへの追加
- iPhone：Safariで公開URLを開き、共有 → ホーム画面に追加。
- Android：Chromeで公開URLを開き、メニュー → アプリをインストール／ホーム画面に追加。

## 注意
- HTTPSで公開してください。Service WorkerとPWA機能にはHTTPS（またはlocalhost）が必要です。
- 履歴・設定は同じ端末の同じブラウザ内に保存されます。端末間同期はありません。
- ブラウザのデータ消去で履歴や設定が消える場合があります。
- このアプリは計算補助用です。実際の支払額は必ずレジの請求額以上にしてください。
- 切り下げの結果が請求額を下回る場合、アプリは支払額を請求額まで引き上げて表示します。

## 更新
ファイルを変更してGitHubへ再アップロードした際、オフライン版の更新が反映されない場合は、`service-worker.js` の `CACHE_NAME` のバージョン番号を変更してください。


## v2.2.0 デザイン変更
- 画面構成は従来版を維持し、青系のアクセントカラーを緑系に変更しました。
- ライトモードとダークモードの配色を緑系に統一しました。
- ブラウザのテーマカラーとPWAのテーマカラーも緑に変更しました。


## v2.3.0 の変更点
- 日本語フォントの優先順位と文字の太さ・行間を調整し、読みやすさを改善。
- 金額入力欄を入力中から3桁区切り（例：1,234）で表示。
- テンキー・金額追加ボタン・逆算入力にもカンマ表示を適用。


## v2.4.0 の変更点
- 端数調整の単位と調整方法を、設定ダイアログから端数調整の入力画面へ移動しました。
- 金額を入力しながら、同じ画面で調整条件を変更できます。
- 設定ダイアログにはダークモード・計算完了音・振動のみを残しました。


## v2.5.0 の変更点
- 計算完了音を、短い単音の電子音から、やわらかく上昇する2音のチャイムに変更しました。
- 音の立ち上がりと余韻を滑らかにし、控えめな倍音を加えて自然な響きに調整しました。
- 計算完了音のON/OFF設定はこれまでどおり利用できます。
